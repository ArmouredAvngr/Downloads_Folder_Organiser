# Downloads Folder Organiser

A lightweight, zero-dependency Python utility that automatically declutters your `Downloads` folder by sorting files into categorized subfolders. Works universally across any Windows, macOS, or Linux user account.

## 📂 How It Organises Files

| Subfolder Created | Supported File Extensions |
| :--- | :--- |
| **Images** | `.png`, `.jpg`, `.jpeg` |
| **Documents** | `.pdf`, `.txt`, `.docx`, `.pptx` |
| **Video and Audio** | `.mp4`, `.mp3`, `.wav`, `.flac` |
| **Compressed Files and Software Packages** | `.zip`, `.exe`, `.rar`, `.7z`, `.msi`, `.tar`, `.dmg`, `.apk` |

## 🚀 How to Use

### Option 1: Windows Executable (No Python Required)
1. Go to the **[Releases](https://github.com)** page on the right.
2. Download **`organiser.exe`** under **Assets**.
3. Double-click `organiser.exe` to automatically organize your Downloads folder. *(Note: If Windows SmartScreen appears, click **More info → Run anyway**).*

### Option 2: Run via Python (Windows / macOS / Linux)
1. Clone or download this repository.
2. Run the script using Python 3:
   ```bash
   python Organiser.py
   ```
